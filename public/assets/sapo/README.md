# Sapo assets

This build intentionally does not bundle copied customer logos, third-party photos, or unverifiable Sapo product screenshots.

Add only assets you are authorized to reuse. Recommended semantic filenames:

- restaurant-pos.webp
- qr-order.webp
- cafe-order.webp
- milk-tea-topping.webp
- billiards-timer.webp
- karaoke-room.webp

Whenever you add an external asset, record its source and reuse permission/context in `/ASSET_SOURCES.md`.
